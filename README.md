# D项目C版本

## 当前 FB 配置隔离

主仓库使用固定配置编号 `main`，后台入口为「主仓库 · zenittra.com」。C、E、F、G、I、J、K 各版本独立读取 `repository_fb_pixels`，每版最多 5 个。空配置或读取失败不使用旧的共用像素。LINE、订单、编号逻辑保持原样；跨站重复填写同一 ID 仍会汇总事件。

独立的两页式贷款需求登记站点。

- `index.html`：贷款金额选择页
- `apply.html`：资料申请表与成功状态
- `styles.css`：响应式视觉样式
- `app.js`：金额传递、表单验证和 D 项目 Supabase 回传

客户填写资料：姓名、电话、出生年月日、LINE 帐号、贷款金额、是否为警示户。

站点前台不显示公司名称。客户资料继续进入现有 D 项目后台。
